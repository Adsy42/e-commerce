# Noureli

This directory contains Noureli's material. Read `store.json` before work. The permanent Shopify domain and stable shop ID are not yet configured: no Shopify access is connected or verified.

- Inherit root instructions and shared skills; use `brand/` for this store's positioning and voice.
- Keep this store's material here. Do not import another store's private content or account sessions.
- Live external work requires the isolated Noureli runtime and verified store-only connections. A full monorepo checkout is administrative.
- Use only the Noureli secret bindings declared in the manifest, injected through secure runtime settings. Never write their values into files or chat.
- Verify the permanent Shopify domain and shop ID before external operations. For other apps, verify the provider's stable account/workspace identity too.
- Keep customer/order-level records and personal data in external private storage. Commit only aggregated non-personal reports.
- Record material decisions and authorized live changes in `operations/`. Do not publish, send campaigns, modify prices, delete records, or change billing/permissions without authorization for the action.
